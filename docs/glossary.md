# Glossary

- **Blue**: Locate/identify indicator; not a binary health label.
- **Green**: Healthy proxy, binary class `0`.
- **Yellow**: Fault proxy, binary class `1`.
- **COCO**: Common Objects in Context annotation format.
- **ROI**: Region of interest containing the LED or LED assembly.
- **Fault recall**: Recall for yellow/fault examples; a missed fault is operationally more costly than a false alarm.
- **Parity test**: Comparison proving desktop and embedded preprocessing/inference agree on identical inputs.
